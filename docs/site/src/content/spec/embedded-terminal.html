Embedded Hovel CLI

Click Hovel or press Alt+H to open its interactive CLI in the selected workspace. Alt+B restores Burrow management. Each workspace keeps its own CLI draft and background output.

Controls

Open/Close Hovel CLI in MenuStart or end this frontend-owned process.

Keys inside the pane belong to Hovel unless Burrow reserves them. Ctrl+B and Ctrl+H keep their text-editing behavior. Open dialogs must be finished or cancelled before switching.

Copy and paste

  • Drag selects only the middle panel. Ctrl+C or Copy copies; Escape clears selection.
  • Without a selection, Ctrl+C interrupts the embedded program.
  • Ctrl+Shift+V pastes. Ctrl+Shift+C copies when forwarded by your terminal.
  • Alt+S toggles native terminal selection, which can include sidebars.
  • Alt+mouse passes through to applications.

Selection never copies automatically. Clipboard tools are used when available; OSC 52 fallback reports “Copy sent to terminal” because the terminal can refuse it. Unbracketed pasted newlines become spaces, preventing implicit command submission.

Exit and restart

Hovel quit or exit ends only the embedded CLI. The pane remains visible and requires an explicit restart; commands are never replayed.

Closing the CLI does not shut down Hovel or prove a dispatched throw was cancelled. Inspect Hovel history before repeating work. Burrow quit ends embedded CLI/editor processes; its separate connection review controls retained SSH resources.

The daemon indicator is independent of the CLI. A pane can show CLI: exited while its daemon is still connected. Restart CLI cannot restart a missing or stale daemon.

Terminal limits

The pinned emulator clips existing output rather than reflowing it on resize. Old wrapped fragments can remain until the application redraws. Burrow never injects redraw keystrokes that could answer a pending confirmation.

One Bubble Tea program owns the physical terminal. PTY dimensions and cursor coordinates are pane-local; extended keyboard protocols and universal terminal-app compatibility are not promised. Interactive terminal bytes are not logged.

See shared SSH shells for their separate control and lifetime rules.
