Install and launch

Burrow supports Linux amd64 and requires OpenSSH client tools. It installs its pinned Hovel runtime on first workspace launch; the SSH target needs only a running SSH server and your authorized account.

Install a release archive

Download the Linux amd64 archive and SHA256SUMS from the same GitHub release. Run these commands in the download directory, replacing VERSION with that release's version:

RELEASE_VERSION=VERSION
sha256sum --check --ignore-missing SHA256SUMS
mkdir -m 700 "$HOME/burrow-$RELEASE_VERSION"
tar -xzf "burrow-v$RELEASE_VERSION-linux-amd64.tar.gz" -C "$HOME/burrow-$RELEASE_VERSION"
export PATH="$HOME/burrow-$RELEASE_VERSION:$PATH"
burrow --help

Proceed only if verification succeeds for the downloaded archive. Extract into a new directory. Add its path to your shell configuration for future sessions.

Alternative: install the release wheel

Download the wheel and checksums from the same GitHub release. After verification, install the local wheel:

sha256sum --check --ignore-missing SHA256SUMS
pipx install ./burrow_ssh-VERSION-py3-none-manylinux_2_28_x86_64.whl
burrow --help

Replace VERSION in the filename. The distribution is burrow-ssh; burrow is its console command. Python launches the bundled Go executable.

Build from source

git clone https://github.com/Bochner/burrow.git
cd burrow
aspect burrow package
mkdir -m 700 "$HOME/burrow-install"
tar -xzf bazel-bin/core/cmd/burrow/package.tgz -C "$HOME/burrow-install"
export PATH="$HOME/burrow-install:$PATH"
burrow --help

Choose a fresh installation directory. To reproduce a release, check out its tag before building. Aspect supplies the declared Go and packaging toolchains.

Open a workspace

burrow --workspace "$HOME/burrow-lab"

Use a short absolute canonical path under a trusted parent. Burrow creates absent private workspace directories and refuses symlinks, unsafe permissions and socket paths over 90 bytes.

Enter connect for guided entry, F1 for help or Ctrl+P for the menu. Continue with connections and workspace navigation.

For JSON setup without a terminal interface:

burrow --workspace "$HOME/burrow-lab" workspace open
burrow --workspace "$HOME/burrow-lab" workspace inspect

open initializes or reuses a workspace; inspect verifies an existing daemon without initializing it. status is an alias for open. Global flags go before the command.

Offline setup

First launch downloads and verifies the exact Hovel v0.4.4 wheel without running pip. Later launches use the verified cache under ${XDG_CACHE_HOME:-$HOME/.cache}/burrow/hovel/0.4.4. A configured XDG_CACHE_HOME must be absolute.

# Reuse a populated, verified cache.
burrow --workspace "$HOME/burrow-lab" --offline workspace open
# Populate a fresh cache from the exact pinned wheel.
burrow --workspace "$HOME/burrow-lab" --offline \
  --hovel-package /absolute/hovel-0.4.4-py3-none-manylinux_2_28_x86_64.whl workspace open

Obtain the wheel from Hovel v0.4.4. Different wheels and arbitrary existing or remote daemons are refused. Integrity pins live in the package verifier.

Upgrade deliberately

  1. Download and verify the intended release, then extract into a fresh directory. For a wheel, use pipx install --force /absolute/new-wheel.whl.
  2. Inspect active connections and retained work. Keep the previous binary while its resources need it.
  3. For a manager update, review workspace restart. It ends that manager's resources and registers the current executable.
  4. For a Hovel runtime change, use the new executable's restart command below. Review before confirming: it ends live sessions and launches the new pinned daemon.
  5. Reconnect explicitly and re-export chains whose bindings changed. Saved settings and collected evidence remain.
burrow --workspace /absolute/workspace restart

Ordinary launch never replaces a mismatched daemon automatically. See troubleshooting for stale receipts or uncertain ownership.

To uninstall a wheel, use pipx uninstall burrow-ssh. Workspaces, agent skills, retained processes and the Hovel cache remain; close live resources deliberately before removing the frontend.
