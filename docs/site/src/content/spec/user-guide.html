Start here

Burrow manages SSH connections, shared shells, tunnels, files and commands from a Linux terminal. It installs and starts Hovel for workspace state and collected evidence.

Your first connection

  1. Install Burrow and open a private workspace.
  2. Enter connect in the management prompt. Fill in the host, account and connection name.
  3. Review the actual SSH command, confirm, and complete authentication. Wait for connected.
  4. Save the connection settings when offered, if you want to reuse them.
  5. Enter shell gateway, replacing gateway with your connection name. Press Ctrl+] to return to management while retaining the shell.
burrow --workspace "$HOME/burrow-lab"

Burrow uses StrictHostKeyChecking=no and UserKnownHostsFile=/dev/null for targets and jump hosts. It does not verify the server against a saved user trust record. Read host trust and authentication before connecting.

Know the resources

ResourcePurpose
WorkspaceA private directory for settings, live-resource records and evidence. Select the same absolute path in every frontend.
ConnectionA named, authenticated SSH transport. Shells, transfers and forwarding reuse it.
ProfileNon-secret settings for a future connection. Loading a profile never connects.
ShellA retained interactive terminal with one controller and independent observers.
RunA retained command with separate stdout, stderr and execution results.
CollectionSaving run output as Hovel artifacts. Viewing live output alone does not save evidence.

Versions and reference

The book follows the current source. Check the release notes for your installed version; burrow capabilities describes its actual command contract. The public module identity burrow@0.1.0 is independent of the application version.

The API tab documents commands, parameters, results and approval rules. The website Reports tab contains CI evidence. Your workspace's reports command reads operational Markdown reports.

Linux amd64 is the supported operator platform. SMB, WinRM, automatic server deployment and legacy LazySSH plugins are outside the implemented workflows.
