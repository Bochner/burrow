User guide

Burrow is the planned Go successor to LazySSH. No production executable, package, or runtime installation command exists yet. Bounded development prototypes are available in the repository.

Initial scope

Linux is the initial operator platform. Hovel integration is primary; standalone SSH management is desirable if shared behavior keeps the added complexity small.

The accepted authentication baseline includes passwords, encrypted keys, SSH agents, host-key verification, SSH config aliases, and jump hosts.

Connection lifetime

The intended Hovel experience distinguishes detach from close. Standalone initially closes its resources on exit. Daemon restart recovery remains a separate decision.

Follow the work

The implementation-ready SSH specification map tracks the decisions. Useful SSH parity covers shells, file transfers, forwarding, and saved connections; detailed acceptance criteria remain open.

Existing LazySSH plugins need not run unchanged. Remote scripts, local scripts invoking Hovel, and local tools using SSH tunnels are separate integration questions. SMB and WinRM implementation remain outside this map.
