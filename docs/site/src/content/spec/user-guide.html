User guide

Burrow is the Go successor to LazySSH. The production Linux amd64 package supports verified Hovel workspace setup, retained SSH connections and saved connection collections. Start with the setup and launch guide.

Connect and save settings

The connection guide covers passwords, encrypted keys, SSH agents, host-key verification, SSH config aliases and jump hosts. After successful interactive authentication, Burrow offers to save the settings for a future session.

Each workspace automatically receives a private burrow-profiles.json template with instructions and an inactive example. Follow saved connection collections for a filled-out JSON example and commands to create, save, edit, delete, load and back up profiles. Opening a collection only displays settings; connect explicitly when ready.

Connection lifetime

Quitting Burrow leaves the workspace daemon and live connections running. Reopen the same workspace to manage them, or use close NAME to review and end a connection. Editing or deleting a saved profile changes future connections only. Saved settings contain no passwords or private-key contents.

Follow the work

The SSH specification map tracks the remaining work. Interactive shells, file transfers and forwarding remain separate tickets; current SSH masters are shell-free.

Existing LazySSH plugins need not run unchanged. Remote scripts, local scripts invoking Hovel, and local tools using SSH tunnels are separate integration questions. SMB and WinRM implementation remain outside this map.
