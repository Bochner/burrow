Burrow book

Project scope, integration boundaries, and development conventions. Start with the user guide for verified workspace launch, saved connection collections and retained SSH connections. The book covers independent interactive shells with background/resume, local and remote forwarding, connection-owned SOCKS proxies, and file browsing and transfers.

The commands and scripts guide adds worked examples for streamed, inline, staged and existing remote scripts, independent stdin, reviewed execution, cleanup and collected results. Dedicated streaming viewers, local tools and reports/chains remain separate work.
