Burrow book

Start with the operator introduction and its version table. This book describes current source, including clearly marked unreleased work beyond the source-only v0.1.0 development release.

  1. Install and launch, choose a workspace, then connect and save settings.
  2. Use shells, forwarding and files through the same connection.
  3. Run commands and scripts, local tools, Ubuntu surveys or Hovel chains.
  4. Install agent workflow skills and follow activity with current source.
  5. Review quit and resource lifetimes; use troubleshooting when an operation refuses or its result is uncertain.

The API reference and CI Reports have their own tabs. Collected operational reports belong to your workspace and are documented in Ubuntu surveys and reports.
