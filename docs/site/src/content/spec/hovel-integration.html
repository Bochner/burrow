Hovel integration

Burrow will use Hovel's public integration contracts. SDK consumption, package lifecycle, logging, credential ownership, and terminal placement are being investigated before selecting the SSH transport or Charm dependency family.

Boundary requirements

Hovel module stdout belongs exclusively to framed JSON-RPC. Terminal rendering needs its own supported route. Reuse daemon-owned state and existing Hovel execution and Mesh capabilities wherever their contracts fit.

Evidence and decisions

Read the Hovel integration research and the decision map. Research recommendations are not approved architecture, and no external SDK build or live SSH integration has been proven by this repository.
