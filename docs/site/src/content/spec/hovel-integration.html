Hovel integration

Burrow uses Hovel’s public SDK and protocol through the single burrow@0.1.0 module for workspace inspection, saved profiles and retained SSH connections. See connection operation and legacy-module transition.

Boundary requirements

Hovel module stdout belongs exclusively to framed JSON-RPC. Terminal rendering needs its own supported route. Reuse daemon-owned state and existing Hovel execution and Mesh capabilities wherever their contracts fit.

Evidence and decisions

Read the Hovel integration research and the decision map. Research recommendations are not approved architecture, and the linked initial research predates the production SDK and controlled SSH acceptance. Historical prototype identities are not production modules.
