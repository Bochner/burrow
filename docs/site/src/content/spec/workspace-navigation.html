Workspace navigation

The production frame keeps workspaces above a fixed midpoint New/Menu row, with workspace-grouped shell navigation below. The Burrow tab retains saved, active SSH and tunnel sections, command output and completion. The Hovel tab hosts its interactive CLI; the SSH shell list remains unimplemented until its own MVP tickets land.

The workspace list contains only explicit paths opened in this frontend session. The pinned public Hovel contract has no cross-workspace enumeration operation. Burrow neither scans directories nor persists another live-resource registry. New opens a form showing the exact canonical destination; Enter or Launch invokes the same verified workspace launch operation as the CLI, preserving its offline/package options and refusal policy. Selecting a known workspace only verifies it; it never launches replacement daemons, reconnects SSH or closes other workspace resources.

Each workspace retains its command draft, completion, history, output and scroll position, selected connection, tab and focus. Asynchronous commands and timers carry their originating workspace and a single-use request identity. A delayed result updates its original workspace. Escape can dismiss a pending launch; its completion does not steal the selected workspace, and launch failures remain in the originating workspace output.

The center shrinks with terminal width, and both sidebars remain visible while narrowing as needed. Tables keep left-aligned section titles and centered headers and values with Catppuccin Mocha semantic colors. Long values truncate within their columns; selected connection details remain available through metadata. There is no blocking 160×40 resize screen. Extremely small terminals show a clipped application view and allow Ctrl+C to exit while suppressing hidden controls. Modal input captures pointer events and preserves the management draft.

The Hovel bubble is green only after a recent verified success, yellow while checking, unknown or older than eight seconds, and red after verification fails or refuses identity. The selected workspace is polled without overlapping checks, normally three seconds after an observation. Metadata shows last-success age, measured verification duration, last-known PID and endpoint. Verification includes local receipt/process checks: its duration is not SSH or network latency. Hovel daemon identity, the Burrow connection owner and SSH connection snapshots are separate states.
