Saved connection collections

A profile is a non-secret connection recipe. A collection is its JSON file. Opening, listing or selecting profiles never authenticates, resolves SSH aliases or creates live resources.

Default collection

Opening a workspace creates WORKSPACE/burrow-profiles.json if absent. Existing content is preserved; files are private, mode 0600. Another selected collection remains the default until explicitly changed.

burrow --workspace /absolute/workspace workspace open
burrow --workspace /absolute/workspace profiles

The generated template contains optional _comment and inactive _example fields. JSON has no comments; keep credentials out of all fields, including explanatory text.

Example collection

{
  "version": 1,
  "profiles": [
    {
      "name": "nas",
      "host": "192.0.2.20",
      "user": "alice",
      "port": 22,
      "key": "/home/alice/.ssh/id_ed25519"
    },
    {
      "name": "build",
      "host": "build-alias",
      "user": "-",
      "port": 0,
      "sshConfig": "/home/alice/.ssh/config",
      "jump": "alice@bastion.example:22"
    }
  ]
}
FieldMeaning
nameProfile and default connection name: 1–24 ASCII letters, digits, underscores or hyphens; starts with a letter or digit.
host, user, portEndpoint. User - and port 0 use SSH configuration; port otherwise defaults to 22.
key, sshConfig, jumpOptional references and route preferences, resolved on explicit connect.
passwordAuthPassword-only preference saved by a password connection. Contains no password; conflicts with key/fixed nonempty agent.
proxyPortSOCKS port on IPv4 loopback; 0/omitted means off.
agentExplicit, agentNormally omit. Set true plus a socket path to fix an agent, or true plus an empty string to disable it.

Paths must be absolute and canonical. Loading validates settings without opening keys or evaluating configuration. Match exec may execute local commands when later connecting; use trusted configuration.

Create and connect

burrow --workspace /absolute/workspace profile create nas 192.0.2.20 alice --key /home/alice/.ssh/id_ed25519
burrow --workspace /absolute/workspace profile select nas
burrow --workspace /absolute/workspace profile connect nas --prompt

Create saves settings. Select displays them. Connect uses the normal resolved SSH review and private authentication flow. --as nas-maintenance chooses a different live name. Unattended --yes starts an asynchronous key/agent attempt; inspect until connected.

Save a successful connection

profile save gateway
profile save gateway --as home-gateway

Only an authenticated active owner supplies reusable settings. Burrow also offers saving after interactive connection success. Skipping or failing the save leaves the connection alive.

Profiles retain aliases and override choices, not resolved addresses, temporary agents, sockets or credentials. Older knownHosts fields must be removed before loading.

Edit or delete

profile edit nas 192.0.2.21 alice --port 2222 --key /home/alice/.ssh/id_ed25519
profile delete nas

Edit replaces the whole recipe; include every option you want to keep. Review before confirming. Changes affect future connections only; active resources and collected evidence remain.

CLI responses include collection path and revision. Repeat them with --collection PATH --revision HASH --yes to refuse concurrent changes. The TUI carries those bindings automatically.

Open and back up collections

# Create or select a collection in a trusted directory.
burrow --workspace /absolute/workspace profile collection /home/alice/homelab.json
# Select an existing file without connecting.
burrow --workspace /absolute/workspace profile load /home/alice/homelab.json
# Backup destination must be new.
burrow --workspace /absolute/workspace profile backup /home/alice/homelab-backup.json

Loading a backup selects the backup itself for future edits. Two workspaces selecting the same file share profile changes but retain separate live resources. Back up external collections separately from the workspace.

Collections are limited to 1 MiB. Invalid JSON, unknown fields, duplicate names, unsafe paths and conflicting revisions are refused. Atomic saves preserve earlier data on pre-replacement failure; synchronization failures can mean uncertain durability. Backups are never overwritten.

Terminal actions

Focus Saved with F6, choose a row, then Enter for actions. Actions populate the prompt for review; clicking a row alone never connects. Tab completes names and options. See Edit in Vim for the private profile editor.

The profile API lists command syntax and result shapes. Use connection chains for confirmed Hovel automation.
