Named SSH connections

A connection is a named OpenSSH master without an interactive shell. Shells, forwarding, file transfers and runs reuse it. The CLI and TUI operate on the same retained owner.

Connect and inspect

Open a workspace first. Bare connect starts guided entry; a complete command selects its name, host and account directly.

burrow --workspace /absolute/workspace workspace open
burrow --workspace /absolute/workspace connect gateway server.example --user ubuntu --prompt
burrow --workspace /absolute/workspace inspect gateway
burrow --workspace /absolute/workspace connections

The first connection command reviews and authenticates on the controlling terminal. For unattended key/agent use, omit --prompt; --yes approves an asynchronous attempt. Inspect until the state is connected: launch acknowledgement alone is not authentication success.

OptionPurpose
--user USERAccount; - uses SSH configuration.
--port PORTOverride SSH configuration or the default 22.
--key PATHPrivate-key reference. Default selection uses current-user OpenSSH identities.
--agent PATHExplicit agent socket accessible to the daemon.
--ssh-config PATHTrusted configuration; defaults to ~/.ssh/config.
--jump HOPSComma-separated [USER@]HOST[:PORT] hops.
--passwordPassword-only authentication with hidden entry. Cannot combine with a key or explicit nonempty agent.
--promptWait for private interactive authentication.
--yes --review HASHApprove the exact returned recap. Changed settings require a new review.

Names use 1–24 ASCII letters, digits, underscores or hyphens and start with a letter or digit. Socket paths must fit 90 bytes. Quote paths with spaces.

Review and authenticate

In the TUI, Tab or arrows choose the confirmation and Enter submits; Escape cancels. Bare connect presents one editable form before review. Incomplete argument-bearing commands return validation errors.

Authentication has a two-minute limit. Interactive entry allows three password attempts; an explicitly supplied target value is sent once. Cancellation attempts cleanup of only that connection creation, preserving siblings. Inspect any cleanup uncertainty.

Aliases and jump hosts

burrow --workspace /absolute/workspace connect build build-alias --user - --prompt
burrow --workspace /absolute/workspace connect gateway server.example --user ubuntu \
  --jump alice@bastion.example:22 --prompt

Burrow resolves supported SSH settings before review. Match exec can execute local commands during resolution, so use trusted configuration. Forwarding directives are not imported; create listeners explicitly.

A host-specific IdentityAgent, including none, overrides the frontend's SSH_AUTH_SOCK; explicit --agent overrides both. Jump hosts resolve their own agent settings. Changing an agent after daemon startup does not refresh the daemon's environment; select the current accessible socket explicitly.

Host trust and private input

Targets and every jump hop use StrictHostKeyChecking=no and UserKnownHostsFile=/dev/null. Existing user trust files are preserved but unused; there is no separate host-key review.

Ordinary TUI password/passphrase fields are visible while typing. Bare --password, chain authentication and CLI secret prompts use hidden input. Answers travel through a private, short-lived frontend endpoint and anonymous pipe; they stay out of Hovel inputs, logs, saved settings and child arguments.

--password VALUE also accepts a supplied target password. That value can be exposed in the invoking process arguments and shell history. Prefer the bare flag. Use --password=VALUE for a leading dash or empty value; the limit is 4,096 bytes without NUL, CR or LF. Automatic target values are never sent to jump-host challenges.

Older collections containing knownHosts must have that removed before loading. The retired --known-hosts and --trust flags are refused.

SOCKS for local tools

proxy create gateway 1080
proxy inspect gateway
proxy remove gateway

Create adds a SOCKS4/5 TCP listener to the existing master. A port alone binds to 127.0.0.1; explicit IP:PORT selects another address. A broad bind exposes unauthenticated proxy access. Review create/remove before confirming.

Configure your client with the inspected endpoint and remote DNS. SOCKS is TCP forwarding, not a VPN or UDP/ICMP route. Listener existence does not prove destination reachability.

For creation during connect, -proxy selects port 9050; -proxy 1080 selects another port. Saved profiles retain this preference. Live proxy changes do not change saved settings. Removing a proxy preserves the master and sibling forwards; accepted streams may finish.

Retain, reconnect or close

burrow --workspace /absolute/workspace close gateway
# After approving the returned review:
burrow --workspace /absolute/workspace close gateway --yes --review HASH

Close ends that connection's master, shells, transfers and listeners. Sibling connections, saved profiles and collected evidence remain. Unknown files or replaced sockets refuse cleanup and remain for investigation.

Keep-running quit retains the connection. Lost connections require explicit reconnect NAME HOST --user USER with the desired settings. Reconnect requires a retained owner that can verify and clean its old creation. It cannot adopt unidentified reservations after owner loss.

Terminal controls

Tab completes commands; F1 opens help; Ctrl+P opens the menu. Use PgUp/PgDn for output and Alt+Up/Down for the connection inventory. See navigation and copy and paste controls.

Legacy syntax and older owners 
connect -ip server.example -port 22 -user ubuntu -socket gateway -ssh-key /absolute/key

Legacy spellings map to the same reviewed flow; duplicate fields are refused. -shell and -no-term are unsupported: open shells explicitly.

Opening a workspace updates the base module without terminating old owners or rewriting chains. Recognized earlier connection owners can still be inspected, saved and explicitly closed. Stop legacy submissions and close their resources before uninstalling burrow-connection@0.1.0 through Hovel. Unknown owners require investigation.
