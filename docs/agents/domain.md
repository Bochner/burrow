# Domain documentation

This is a single-context repository. Read root `CONTEXT.md` before exploring,
and read relevant decisions in `docs/adr/` when that directory exists. Use the
glossary's terms; call out disagreements with accepted decisions explicitly.

Create ADRs when decisions are made, not to convert a research recommendation
into an apparent commitment. Missing ADRs are normal during bootstrap.
Research belongs in `docs/research/`; a Wayfinder decision lives in its ticket,
with a link from any resulting ADR rather than competing resolution histories.

Source: [Matt Pocock's domain template](https://github.com/mattpocock/skills/blob/3cca18b368ae95cdbdebbff572ccafa662551015/skills/engineering/setup-matt-pocock-skills/domain.md).
